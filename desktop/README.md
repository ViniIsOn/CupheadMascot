# CupheadMascot para Windows

Aplicativo desktop x64 para Windows 10/11. A arena permanece vertical no centro da janela; o editor usa mouse e a batalha usa teclado.

## Controles
- Andar: A/D ou setas esquerda/direita
- Pular: Espaço
- Dash: Shift
- Atirar: J ou Z
- Parry: P
- Mirar em 8 direções: teclado numérico 1, 2, 3, 4, 6, 7, 8 e 9 (segure para mirar e disparar)
- Tela cheia: F11
- Sair da batalha: Esc

## Dados
Projetos, músicas e efeitos importados ficam na pasta de dados do usuário do Windows (AppData/Roaming/CupheadMascot).
Vídeos exportados ficam em Vídeos/CupheadMascot.

A compilação é feita pelo GitHub Actions no workflow Windows Desktop.
